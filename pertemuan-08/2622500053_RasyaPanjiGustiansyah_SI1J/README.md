# pertemuan-08
Membuat web untuk UTS Semester Gasal 2026/2027
- Pembuatan web mencakup HTML,CSS,JavaScript,PHP
- Tema web adalah blog pribadi dengan header diatas, navigasi bar disebelah kiri konten di sebelah kanan, dan footer ada di bawah tampilan web.
- Penggunaan logo pada header dan penggunaan warna biru dibagian header yang dibuat dalam file "style.css dan style2.css"
- Pada bagian navigasi terdapat 3 menu yaitu "beranda, profile, dan pendaftaran".
- Pada bagian beranda berisi penjelasan singkat tentang diri saya sendiri dan saya menyisipkan 4 foto dalam halaman tersebut.
- Pada bagian Profile berisi biodata saya dan saya menyisipkan 1 foto pada halaman tersebut.
- Pada bagian Pendaftaran berisi form untuk daftar pengunjung yang mengunjungi web saya.
- Untuk warna yang saya gunakan adalah warna biru dan ungu karena warna biru kebetulan warna kesukaan saya dan warna warna tersebut lebih menarik pelihat.
- JavaScript yang digunakan sesuai dengan yang telah diajarkan pada pertemuan-pertemuan sebelumnya.
- Penggunaan hover pada tombol navigasi

# Galat yang ditemukan
- Tidak munculnya hasil css pada halaman web dikarenakan belum di hubungkan ke file style.css
- Tidak dapatnya di submit dikarenakan error codingan pada form no.hp dan nim
- Tidak tervalidasinya hasil submit dari pendaftaran.php

# Penanganan galat
- Menambahkan kode yang menghubungkan style.css ke file .php lainnya.
- Menghapus kode "min" dan "max" pada file pendaftaran.php.
- Menganalisis letak salah dan mengubah beberapa codingan lalu menyambungkan code untuk submit dengan code validasi di file blog.js
